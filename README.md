# 10Qadam — spelling arena

Браузерная spelling-арена. Слушай английское слово, напиши его за 12 секунд и получи очки за точность и скорость. Светлый адаптивный интерфейс, словарь, тренировки, дуэли и баттлы на четверых.

Интерфейс по умолчанию английский; переключатель EN / KZ / RU сохраняет выбранный язык на устройстве. Официальные слоганы: «10QADAM — Spell Your Way, Step by Step.» и «10QADAM — Äripten sözge, sözden jeñiske!». В словаре доступны английские определения и переводы на казахский и русский.

Озвучка выбирает наиболее качественный доступный английский голос и немного замедляет произношение. Конкретный голос зависит от браузера и установленных голосов устройства; при отсутствии английского голоса приложение показывает сообщение, а не использует произношение другого языка.

## Обучение и страницы

Главная `/` знакомит с 10Qadam и предлагает выбрать A1, A2, B1, B2 или C1. Прямые ссылки `/learn/B1`, `/learn/B2`, `/learn/C1` сразу открывают нужную подборку; базовые уровни не обязательны. Это учебные подборки, не сертифицированный тест CEFR.

При регистрации пользователь выбирает A1–C1. Уровень сохраняется в Supabase Auth `user_metadata.learning_level`, восстанавливается при входе и задаёт стартовую подборку обучения и словаря на любом устройстве. В профиле его можно изменить; старым аккаунтам и пользователям OAuth без уровня предлагается выбор после входа. Прямая ссылка на конкретный уровень имеет приоритет при загрузке. Это самооценка для обучения, не проверенный уровень и не основание для рейтинга/прав доступа; миграция БД не требуется.

- Карточки: 7 589 слов и выражений по пяти уровням, переворот, озвучка, отметки «знаю / повторить». 7 579 записей импортированы из CEFR-J/Octanove с определениями WordNet, десять сохранены из прежней подборки. Изученные слова сохраняются только на текущем устройстве.
- Библиотека слов: все пять уровней, поиск по словам/определениям/доступным переводам, страницы по 40 записей. Большинство новых записей имеют английские определения, а не RU/KZ-переводы; это явно отмечается в интерфейсе. Автоматические непроверенные переводы не добавляются.
- Диктант: 60 оригинальных предложений, по 12 на уровень; сессия из пяти предложений, 35 секунд на каждое. Повтор не продлевает время. Процент — нормализованное посимвольное сходство по расстоянию Левенштейна, с разбором ошибок. Регистр и пунктуация игнорируются.
- В учебном разделе можно выбрать скорость/английский голос и скрыть или изменить стиль Кырана. Выбор сохраняется локально.
- Арена `/arena`: дуэли, баттлы и соло на A1, A2, B1, B2 и C1. Форматы «Слова» и «Предложения» имеют отдельные очереди и рейтинги со стартом в 1000. Предложения: 5 раундов по 35 секунд, неограниченные повторы в пределах раунда; побеждает средняя посимвольная точность, скорость не даёт бонуса. При равной точности — ничья. Сервер проверяет время, текст и начисляет Elo. Уровень аккаунта задаёт стартовый выбор, без обязательного прохождения A1/A2.
- `/plan`: Gemini составляет семидневный план по уровню, цели, времени и пожеланиям. Только после входа и согласия на передачу данных Google; ключ хранится на сервере. До трёх попыток на аккаунт и 100 на сайт за сутки UTC. План и отметки выполнения сохраняются только в этом браузере, отдельно по аккаунтам. Это учебный ориентир, не сертификация и не обещание повышения CEFR. Настройка: [docs/ai-plan.md](docs/ai-plan.md).
- `/words`, `/leaderboard`, `/profile` имеют отдельные адреса. Vercel rewrites поддерживают открытие глубоких ссылок и обновление страницы.

Источники, лицензии, ограничения и воспроизведение импорта: [docs/vocabulary.md](docs/vocabulary.md). В опубликованной версии доступны `/vocabulary-sources.html`, оригинальные уведомления и скачивание адаптированного JSON. CEFR-метки относятся к заголовочному слову, не к каждому значению словаря; авторы источников не подтверждают и не спонсируют приложение.

## Локальный запуск

Нужен Node.js 22.12+.

```sh
npm install
npm run dev
```

Проверка и сборка:

```sh
npm test
npm run build
```

Без настроек Supabase доступны соло, словарь A1–C1 с озвучкой, локальная история и явно обозначенное демо с ботами. Настоящая регистрация, поиск игроков, рейтинг и таблица лидеров требуют подключения Supabase. Приложение не подменяет реальных игроков ботами.

## Подключение Supabase

1. Создай проект Supabase.
2. Выполни `supabase/schema.sql` в SQL Editor своего проекта.
3. Создай `.env.local` по образцу `.env.example`. Укажи URL проекта и **публичный anon/publishable ключ**, не service-role и не secret key.
4. Для входа Google включи Google Provider в Supabase Authentication. Добавь callback Supabase в Google OAuth и выставь `VITE_AUTH_GOOGLE=true`. До настройки кнопка Google скрыта. Инструкции в `supabase/README.md`.
5. В Supabase Authentication → URL Configuration добавь адрес опубликованного сайта в Site URL и Redirect URLs; для разработки добавь `http://127.0.0.1:5173`.
6. Перезапусти dev-сервер после изменения переменных.

## Публикация на Vercel

1. Vercel → Add New → Project → импортировать `Shikitoafk/10Qadam`.
2. Framework: **Vite**, Build: `npm run build`, Output: `dist`.
3. Добавь `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` в Environment Variables.
4. Добавь `VITE_SITE_URL` с постоянным адресом сайта, например `https://10qadam.vercel.app` (используй фактически назначенный Vercel адрес).
5. Deploy. Если переменные добавлены после первого запуска, сделай Redeploy.

Проект не содержит секретов. Все `VITE_*` переменные видны в браузере; безопасность данных обеспечивают права доступа и серверные RPC в Supabase.

## Поиск Google

В сборке с `VITE_SITE_URL` создаётся `sitemap.xml` и canonical URL. Открытая главная страница содержит описание игры, уровни и правила. Добавь полный HTTPS-адрес в Google Search Console как URL-prefix resource, подтверди его через HTML-тег в `index.html`, отправь `/sitemap.xml` и запроси индексирование главной. Регистрация и личные данные не выводятся в исходном HTML. Индексация и позиции не гарантируются.

## Правила

- 10 разных слов одного уровня; максимум 12 секунд на слово.
- Одна попытка; крайние пробелы и регистр букв не влияют на ответ.
- Верный ответ: 100 очков + до 50 за скорость. Неверный: 0.
- Побеждает количество верных слов, затем очки за скорость. Полностью равные результаты дают ничью.
- A1, A2, B1, B2 и C1 имеют независимые рейтинги; соло и демо не меняют рейтинг.
- Соло переключает слово сразу после ответа; онлайн имеет общие серверные интервалы для всех участников.

## Ограничения первой версии

- Для браузерной озвучки требуется поддержка Web Speech API и английский голос на устройстве. Рекомендуются Chrome/Edge. Слова передаются клиенту для TTS, поэтому опытный пользователь может извлечь ответ. Сервер не доверяет присланным очкам, но полноценная защита от ботов требует аудиозаписей и отдельной античит-системы.
- Задержка сети учитывается в бонусе скорости. Это MVP, не турнирная система с денежными призами.
- Бесплатный Vercel Hobby предназначен для личного некоммерческого использования.
- Реальная проверка онлайн требует своего Supabase и двух/четырёх отдельных аккаунтов. Не считай успешную локальную сборку проверкой работающего облачного матчмейкинга.

Схема базы, настройка авторизации и проверка онлайн: [supabase/README.md](supabase/README.md).
